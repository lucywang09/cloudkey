# CloudKey Product Drop - Next.js Starter

A simple starter project for the AWS + Storyblok demo.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Demo starting point

The main marketing content is intentionally hardcoded inside `app/page.tsx`.

For the Storyblok part of the demo, you'll move content such as:

- Hero headline
- Description
- Launch message
- Product image
- CTA
- Product availability

out of the React component and into Storyblok.

## Suggested flow

1. Run the site locally.
2. Push this project to GitHub.
3. Deploy it with AWS Amplify.
4. Connect Storyblok.
5. Move the content into Storyblok.
6. Use the Visual Editor to update the content.
7. Add the Announcement Banner component.
8. Deploy the Storyblok-connected version.
9. Simulate launch day.
